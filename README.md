# Gestion Commerciale ERP

A professional bilingual desktop ERP application for commercial
management, inventory, sales, purchasing and invoicing.

## Technologies

### Frontend
- Java 27
- JavaFX
- FXML
- CSS
- Scene Builder

### Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- REST API

### Database
- PostgreSQL

## Main Features

- User authentication and authorization
- Role and permission management
- Customer and supplier management
- Product and inventory management
- Purchase and sales orders
- Quotations and invoices
- Payment management
- Financial reports and dashboard
- French and Arabic interface
- MAD currency

Currently under development.
